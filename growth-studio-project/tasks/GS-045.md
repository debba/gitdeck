# GS-045 — Image clipboard and download actions

**Phase:** Phase 4 — Media

- Create `src/components/growth/GrowthMediaActions.tsx` and `tests/components/growth/GrowthMediaActions.test.ts`. Extend `src/components/growth/ContentItemDrawer.tsx`, `src/components/growth/calendar/GrowthQueue.tsx`, `src/styles/growth/content-drawer.css`, `src/styles/growth/calendar.css`, `src/i18n/en.ts`, and `src/i18n/it.ts` with reusable per-media copy and download actions.
- Resolve asset-backed media only through `fetchGrowthAssetFile` from GS-040 and retain direct HTTP/HTTPS URL behavior for legacy URL-only media. For images, call `rasterizeGrowthImageToPng` from GS-044, then use `navigator.clipboard.write([new ClipboardItem({ "image/png": blob })])`; do not request clipboard permission eagerly and do not treat text-copy support as image support.
- If image clipboard APIs are absent, fetching/rasterization fails, or the clipboard write rejects, immediately offer or trigger a PNG download from the same user action and show a localized fallback notice. Also provide an explicit Download image action. Sanitize filenames with the GS-044 helper, revoke every temporary object URL, and keep external source links available when a legacy URL cannot be fetched because of CORS.
- Render the actions beside image previews in both Queue and `ContentItemDrawer`; videos retain their existing playback/open behavior and get no image-copy action. Disable duplicate actions while busy, preserve keyboard reachability, and show copied, downloaded, fallback, and error states without closing the drawer or recording publication.
- Tests cover generated SVG and uploaded raster paths, exact PNG clipboard MIME, unsupported `ClipboardItem`, rejected clipboard writes, download fallback, object-URL cleanup, legacy URL failure, video exclusion, Queue and drawer integration, and the absence of outbound social requests.

Acceptance:

- Every accessible image in Queue or the content drawer can be copied as PNG when supported and downloaded otherwise; generated SVG is rasterized at 2x in the browser and no action posts content or rasterizes on the server.
