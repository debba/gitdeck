# GS-032 — Media-aware content drafter

**Phase:** Phase 3 — Editorial plan

- Create `src/server/growth/drafter.ts`, `src/utils/growth/mediaCandidates.ts`, `tests/server/growthDrafter.test.ts`, and `tests/utils/growth/mediaCandidates.test.ts`. Extend `src/server/growth/store.ts` with an account- and repository-scoped `listGrowthAssets` read over the existing `growth_assets` table; do not add upload or import behavior before phase 4.
- Add `POST /api/growth/content/:id/draft` with an optional allowlisted `{ refresh }` body in `src/server/routes/growth.ts`, plus response types in `src/types/growth.ts`, a client fetcher in `src/api/growth.ts`, and account-scope and validation coverage in `tests/server/growthRoutes.test.ts`. Keep the existing `POST /api/growth/content/draft` intervention endpoint unchanged.
- `drafter.ts` turns one `idea` or `draft` item into a draft in place. It collects repository signals through `collectRepositorySignals`, combines `growth_assets` with README and additional-source media through the pure `mediaCandidates.ts` normalizer, and sends profile voice, audience, language, hashtags, avoid text, slot angle, pillar, CTA summary, sources, and verified signals to one `generateStructured` call.
- Normalize the answer into title, body, thread posts, sources, media and alt text. Reuse `normalizeSocialProposals`, `socialProposalIssue`, and the existing platform limits for X, LinkedIn and Mastodon; never accept a model-created media URL outside the supplied candidates. Asset-backed media uses `assetId`; source media uses an HTTP or HTTPS `url`.
- If AI is not configured, produce deterministic, evidence-grounded draft copy and attach the first suitable supplied media candidate when one exists. A draft may remain without media, but must remain `draft` and surface `mediaRequired: true`; the existing store gate still prevents `ready`, `scheduled`, or `published`. Reject drafting ready, scheduled, published, or skipped items with 409, and never overwrite them. Tests cover fallback copy, platform validation, media allowlisting, account scope, protected statuses, and refresh behavior.

Acceptance:

- Planned ideas can be drafted without an intervention; drafts use only verified text and supplied media, include non-empty alt text for attached media, and cannot bypass the mandatory-media workflow.
